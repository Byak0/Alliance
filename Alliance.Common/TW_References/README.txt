1. Launch "Install Ispy.bat" to install the decompiler tool.
2. Launch "Decompile.bat" to decompile the TW_References.dll assembly.
3. You can now point Copilot to the "BannerlordSource" folder for better code suggestions.
4. Launch "GenPDB.bat" to generate the PDB file for TW_References.dll which will help VS debug crashes.
